## 1. Executive summary

The controls pipeline is structurally mature and semantically unguarded. The mechanized half —
control emission for parameters and shared quick filters, zone→widget mapping, root-closure target
wiring, multi-DS retargeting, the coverage ledger, dup-id preflight, PUT id-guard, and gate 7's
on-by-default lint of the LIVE readback spec — is genuinely strong, and run-2's field evidence shows
that chain working end-to-end ("1 param → 1 emitted, 0 unaccounted ✓", anchors 11/11) [E, E-V1].
But every verified defect clusters at the two layers no gate measures: what the .twb *meant* and
what the warehouse *contains*. Headline defects, all adversarially confirmed: (1) categorical
EXCLUDE filters are silently inverted into include lists — the migrated dashboard shows exactly the
rows Tableau hides [G-V1]; (2) datasource-level filters are parsed by no code path at all, so every
sheet shows globally excluded rows, with zero warning [G-V2]; (3) the run-1 blank-tile family —
control values/defaults minted from .twb text and never checked against data — still has no
preventive code path (W2.1 unbuilt; the flip gate 7b is opt-in and tableau never opts in; even when
run, its pass condition cannot flag a bad default) [E-V2, E-V3, V-V1]; (4) native top-N quick
filters lose N and direction, and wildcard filters degrade to a no-op the build log actively
mislabels as a source "All" filter [G-V3, G-V4]. The verification stack measures control EXISTENCE
and WIRING but attests or ignores BEHAVIOR and SEMANTICS: no enforced source-vs-built census
(controls-coverage.json is written and read by nothing [V-V3]), the sidecar scope allowlist is
authored by the code it excuses [V-V4], and lint "reach" credits broken consumers [V-V5]. Sigma's
spec can express nearly everything that's broken — `mode:"exclude"`, text-mode wildcards, relative
dates, typed values, `includeNulls` — so most of the gap is Sigma-can-but-we-don't, not Sigma-can't
[S §A/D]. Genuine product gaps are few and known: Apply button, parameter actions'
click-trigger, filter ordering/context semantics, dynamic zone visibility [S §D]. Separately, the
sigma-workbooks skill's ground truth has drifted: its OpenAPI URL 404s, `/v2/workbooks/spec`
vanished from the published contract, and at least six enum/shape claims disagree with the live spec
[S §E]. Master-matrix tally: **19 FAITHFUL / 7 TRANSLATABLE-BUT-BROKEN / 9 TRANSLATABLE-BUT-UNBUILT /
5 PRODUCT-GAP / 2 UNKNOWN** (42 constructs).

## 3. CRITICAL DEFECTS (ranked)

All verdicts below are from the adversarial verifiers; synthetic-run proofs are the analysis
agents', reproduced independently by the verifiers unless noted.

**D1 — Categorical EXCLUDE inverted into an include list. DATA-WRONG, silent.** [G-V1 CONFIRMED]
Mechanism: `ptl:299-321` collects every descendant `function='member'` with no check of the wrapping
`function='except'` or `user:ui-enumeration='exclusive'` (repo-wide grep: zero handling). Synthetic
exclude-West .twb → `{"kind":"list","members":["West"]}` — byte-identical to include-West. Then
`bcs:5480-5484` emits `mode:'include', values:f['members']`: the dashboard shows ONLY what Tableau
hides. Blast radius: every exclude-mode filter (prevalence M [T §6]); output is non-empty and
plausible, so gate 13/anchors/eyes all pass. Sigma fix-target: `mode:"exclude"` exists on
list/hierarchy [S §A].

**D2 — Datasource-level (and extract) filters entirely unparsed. DATA-WRONG for every sheet, silent.**
[G-V2 CONFIRMED] Mechanism: the only `<filter>` walks are worksheet-scoped (`ptl:592`) and
`//shared-view` (`ptl:1805-1807`); `<datasource>`-child and `<extract>`-child filters match neither;
the converter parses no filter elements at all. Synthetic Segment=Consumer ds-filter: 0 traces in
layout.json, meta, converter output, or any warning. Blast radius: published-datasource shops rely
on these as row-level scoping users "can't see or modify" [T §1] — every tile over-reports. Caught
today only if an anchor value happens to diverge (unattributed).

**D3 — Converter param controls ship default-less (the run-1 blank-tile family).** [G-V5 CONFIRMED,
one narrowing] Mechanism: `tm:4181-4197` captures currentValue but emission at `tm:6121-6132` sets
`values:[]`; date params get a fabricated last-90-days range (`tm:6133-6144`) ignoring the actual
value; `<range>` never parsed → boundless number-range (`tm:6145-6152`); boolean → text-contains.
Narrowing: the Top-N-driver path does apply the default (`tm:~6098-6119`). Live-proven on
partner-crosstab-controls. Related: `tableauParamSwitchToSigma` misses caption-refs and integer
WHENs (`tm:2584,2590`) — [G-V6 CORRECTED: patterns absent but warnings exist, one actively
misleading ("bind control as a filter") for what is a measure-picker]. Blast radius: any consumer of
converter page output; orchestrated runs are backstopped by the stronger scripts path.

**D4 — Value-domain validation does not exist anywhere (W2.1 unbuilt); the flip gate can't do it.**
[E-V2, E-V3, V-V1 all CONFIRMED] Mechanism: scripts pass `.twb` defaults verbatim
(`bcs:6291,6320-6334`); build performs zero warehouse access; `probe-filter-literals.rb` does not
exist (repo-wide find); gate 7b is opt-in and `mt` never passes `--require-control-flip` (only
looker-to-sigma does, migrate-looker.py:1142); even when run, `pc:198`'s pass condition is
base≠flip, so an empty-default baseline vs any real flip = PASS. Field evidence: run-1 ~33 min of
no-data hunts + fed the false GREEN; run-2 avoided it via ~3 min of ad-hoc agent probing —
"ad-hoc agent diligence, not skill code" (run2-postmortem:373). Ranking caveat [E-V1]: run-1's '&'
fix reached the live DM before the final POST — the typed-literal class (D4b) is co-responsible for
the terminal false-GREEN, so W2.2 wiring is equally valuable. **D4b:** the typed-literal lint
(`lib/typed_literal_lint.rb`, tested) is dead weight — zero invocations from orchestrator/SKILL.md/refs
(commit 09e743f: "Not yet wired"); same for visual-similarity.py `--tiles` (W1.7).

**D5 — Wildcard filters silently become "All", and the log mislabels them as source-intended.**
[G-V4 CONFIRMED] `function='matches'` has no code path; synthetic → `members:[]`; `bcs:5475` then
reports "has no explicit members (Tableau 'All') — no Sigma element filter emitted". Data-wrong
(unfiltered rows shown), silent, and the artifact actively lies. Sigma fix-target: text control
modes incl. like/matches-regexp [S §A].

**D6 — Native top-N quick filters lose N and direction.** [G-V3 CONFIRMED] `normalize_filter` never
reads `end/count/direction/units`; synthetic top-10 → `condition_expressions:["SUM([Sales])"]`, N
and DESC gone; `bcs:5469-5521` has no arm for `list+condition` (no else — silent); only RANK-calc
and categorical-set idioms survive. The shared-path warning quotes the expression but never N.
Broader [G-V missed 2]: the missing else arm also silently drops pure condition filters and
`kind:'unknown'` classes per-tile.

**D7 — Shared quick-filter member selections dropped from the control (`values:[]`), silently.**
[B-V1 CORRECTED] The drop is real and worse than reported — no warning, ledger says 'emitted'
(healthy); corpus-proven (orders-overview: 20 selected states + %null% ship as select-all). The
original zero-row-intersection scenario was REFUTED: shared filters and worksheet filters come from
disjoint XML, never dual-surface. Actual defect class: default-state infidelity — dashboard opens
unfiltered where Tableau opened filtered.

**D8 — Worksheet-local ("selected worksheets") quick filters are census-invisible.** [B-V missed 1]
Auto-controls iterate only `meta['shared_filters']` (`bcs:6443`); coverage 'expected' = params +
shared filters — a selected-sheets quick filter lands solely as a locked element filter, loses all
interactivity, and no ledger or gate can ever notice.

**D9 — Date literals passed verbatim.** [G finding 8; synthetic-proven by G, not independently
re-verified — see §7] `#2024-01-01#` flows into startDate/endDate unchanged (`bcs:6583-6584`); no
`#`-stripping anywhere; element path treats date bounds as number-range (`bcs:5514-5520`).

**D10 — Relative-date `anchor` attribute ignored.** [G construct-map, grep-proven; not
independently re-verified] Anchored windows silently compute relative to today; `include_future`
extracted but unused.

**D11 — Cross-page control leakage in page-per-dashboard mode.** [B-V2 CONFIRMED] Page copies carry
identical `filters` targets to the shared master (`bcs:7216-7244`, targets computed once at
:6159-6181); Sigma propagates along source chains, not pages — page A's flip refilters page B, and
copies AND-compose on the master. `cl:171-178` checks same-page reach only; `pc:209` picks
out-of-closure probes from the same-page set: no gate can see it.

**D12 — Dormant `--workbook-patterns` channel.** [G finding 7 + B construct-map, convergent across
two independent analyses; not adversarially re-verified] `mt:3004-3016` never passes the flag, so
`load_param_switches` (bcs:2095, 3904) always no-ops; conv-meta.json's workbookPatterns are read
only by migration-notes.rb. Orchestrated coverage rests entirely on the (stronger) scripts-side
translators; DM-only consumers silently lose pickers.

## 4. VERIFICATION GAPS — what the nets can and cannot catch

**What exists and works** [V-V, E-V3]:
- **Gate 7 static lint** (cl:194-299) — on by default, runs against the LIVE readback spec in both
  `par` (exit 4) and `ap6` (exit 9): dead controls, ghost targets, same-page partial reach,
  zero-controls-from-interactive-source; live-spec placement even catches Sigma's silent
  numeric-target PUT strip. Strongest control construct in the skill. But: it passed 7/7, clean, on
  run-1's fully blanked dashboard — topology only, never values [E-V3].
- **Gate 13 / W1.1 empty-tile** (ap6:1576-1585, exit 18, near-unwaivable) — the enforced v5.5
  backstop; its error text names the run-1 case verbatim. Catches bad defaults ONLY when they blank
  a displayed tile.
- **ERROR_CELL** (verify-warehouse.rb:96-98) — catches #ERROR/Invalid Query on queryable exports;
  text elements are not queryable, so text-template control refs stay uncovered [V-V5].
- **Dup-id preflight** (par:382-403, hard exit 1) + converter id fix (tm:4157, 4081-4087) — the
  run-1/run-2 dup-controlId class is fixed, with one blind spot: element-id and controlId are
  counted in separate buckets while Sigma enforces ONE namespace (run-2 errors.txt:308) [E-V missed 3].

**Control CENSUS: exists twice, enforced zero times** [V-V3 CONFIRMED]:
- `controls-coverage.json` (bcs:6720-6760) is the true source-vs-built census with UNACCOUNTED
  detection — written as a WARN + file that **no gate, script, or doc ever reads** (grep: zero
  consumers). Its 'expected' also excludes action filters and worksheet-local filters (D8).
- `control-scope.json`'s `sourceFilterSignals` is the builder's own record count (bcs:7388) —
  self-referential, a hole the code itself admits (ap6:1073-1076). The scope allowlist is authored
  by the code being verified: a tile the builder misroutes to a column-less root simply drops out of
  scope and gate 7 skips it [V-V4].
- Contrast: the tile census hard-gates. Controls have no equivalent.

**probe-controls.rb (gate 7b): built, shared, fail-closed — and unreachable** [V-V1 CONFIRMED]:
opt-in via `--require-control-flip`; `mt` never passes it; zero invocations in either field session.
Prose mandates exist (fidelity-rubric.md:25 "On EXIT, prove the wiring with the flip test";
phase-6-parity.md §6) and were ignored in both runs — direct evidence that prose obligations don't
execute [E-V missed 2]. Even opted-in: date-range/slider/number auto-SKIP (all-SKIP → advisory
WARN), pass = CSVs differ — wiring proof, never default-validity proof. One-line upgrade available:
it already prints the baseline row count ("0 -> N rows", pc:201); failing on a zero-row baseline
converts it into the bad-default check [E-V missed 4].

**Semantics have no verifier at all** [V-V2 CORRECTED]: nothing compares default value,
selectionMode, or filter-target columnId against the Tableau source (cl:166 extracts elementId
only); `preflight_lint.rb` carries real control-shape rules (C5: single+values-array "the filter
and the default silently drop") and SKILL.md:349 calls it "MANDATORY before any workbook POST" —
but no production script invokes it. Lint "reach" over-credits: a type-mismatched formula ref or a
text-template ref that renders Invalid Query counts as live wiring, keeping dead controls alive
[V-V5]. Visual attestation has no interactivity key — controls appear only as "leaked stubs" and
"missing control" presence checks [V].
